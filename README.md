# 外置转内置（wzznz）

一个基于 **Rust + windui** 的 Windows 图形工具：读取配置文件，把**外置模块**（软件、驱动、脚本、命令）**转为内置** —— 即复制（或解压）到 PE 的 `X:\` 下并按类型执行。

> 适用场景：WinPE / 精简系统制作，把 U 盘或本地磁盘上的外置工具"搬"进内存盘，启动后即为内置状态。

## 特性

- **单文件静态 exe**（约 8 MB），静态链接 CRT，无运行库依赖
- **纯 Win32/GDI + 软件渲染**（windui），**不依赖 OpenGL / DirectX**，PE 环境兼容性好
- **GUI 勾选式操作**：每项右侧显示绿「可用」/ 红「缺失」与「已内置」/「未内置」，并汇总占用大小
- **多类型支持**：软件 / 驱动 / bat / cmd / wcs / CMD（直接执行命令行）
- **压缩包自动解压**：`.zip` / `.7z`
- **同名合并**：同一个显示选项可写多行，勾选后按顺序依次执行
- **无人值守**：`--auto` 命令行模式，无界面直接全选转换
- **内嵌资源**：`dwrite.dll`、`PECMD.EXE`、`DrvIndex.exe`、`7z` 编译进 exe，运行时自动释放并做 CRC32 完整性校验
- **编码自适应**：配置文件自动识别 UTF-8（含 BOM）/ GBK；bat/cmd 落地前自动转 GBK + CRLF 并注入 `@chcp 936`
- **断点标记**：已处理项写入注册表 `HKLM\SOFTWARE\WZZNZ\Installed`

---

## 快速开始

1. 下载 / 构建 `外置转内置.exe`
2. 将 `外置转内置.ini` 与 exe 放在**同一目录**（可参考 [示例配置.ini](示例配置.ini)）
3. 双击运行
4. 在界面中**勾选**需要的模块 → 点【开始转换】

## 配置文件详解

配置文件是工具唯一的输入。**放错位置、字段顺序错、类型拼错**，表现出来的都是「选项不出现 / 显示缺失 / 勾了没反应」。下面按「语法 → 字段 → 落点 → 类型」的顺序讲。

### 1. 文件位置与编码

| 项目 | 要求 |
|------|------|
| 文件名 | 固定 `外置转内置.ini`，程序只认这个名字 |
| 位置 | 必须与 `外置转内置.exe` **同一目录**（读的是 exe 所在目录，不是当前工作目录）|
| 编码 | UTF-8（带/不带 BOM）或 GBK，自动识别 |
| 换行 | CRLF / LF 均可 |
| 不支持 | UTF-16 编码；字段内的英文逗号 |

### 2. 基本语法

- **一行 = 一个动作**，字段用**英文逗号** `,` 分隔，最多 5 个字段：

```
类型,源路径,显示选项,目标文件夹,占用大小
```

- 前 3 个字段**必填**，后 2 个可空。只想写「占用大小」时，第 4 个位置要留空（连续两个逗号）：

```ini
软件,D:\Apps\Browser,浏览器
软件,D:\Apps\Browser,浏览器,,50MB
```

- 空行、以 `;` 或 `#` 开头的行会被忽略；**不支持行内注释**。写成
  `软件,D:\Apps\Browser,浏览器 ; 注释` 时，`; 注释` 会成为字段内容的一部分。
- 每个字段两端的空格会自动去掉。
- 少于 3 个字段的行**直接跳过**；第 6 个及之后的字段忽略。
- 「类型」为空或「显示选项」为空的行跳过。

### 3. 五个字段逐个讲

#### 3.1 类型（第 1 字段）

| 填法 | 含义 |
|------|------|
| `软件` | 复制 / 解压到目标目录 |
| `驱动` | 安装驱动：`.inf` 直接装，压缩包 / 目录交给 `DrvIndex.exe` |
| `bat` | 复制到目标目录后以 `cmd /c` 执行（自动转 GBK + CRLF + `@chcp 936`）|
| `cmd` | 同 `bat` |
| `wcs` | 复制到目标目录后由 `PECMD.EXE LOAD` 执行（自动补 `#code` 声明）|
| `CMD` | **大写**：第 2 字段当命令行直接执行，不复制文件 |

> `cmd`（小写）和 `CMD`（大写）是两种完全不同的类型，别混。
> 类型写得不对（如 `软体`、`BAT`、`软件 `）**不会报错**，该条只是不执行任何动作，但转换后仍会被标记为「已内置」。

#### 3.2 源路径（第 2 字段）

- 绝对路径最稳妥；**相对路径是相对 exe 所在目录**，既不是 ini 所在目录，也不是当前工作目录。
- 支持：单个文件、文件夹、`.zip`、`.7z`。
- 源不存在时：列表标红「缺失」，转换时**静默跳过**（不弹错误），但该选项仍会被写入「已内置」标记。
- `CMD` 类型：本字段是**命令行本身**，不做存在性检查，永远显示「可用」。
- 路径里不能有英文逗号，也没有转义写法。

#### 3.3 显示选项（第 3 字段）

- 界面上的勾选名称，同时是**同名合并的键**和注册表标记的键。
- 名称完全相同 → 合并为一个勾选项（见第 6 节）。
- 中文没问题，但不要带逗号。

#### 3.4 目标文件夹（第 4 字段，可空）

- 只填**目录**，不要填最终文件名。
- 建议填**绝对路径**；相对路径会随启动方式变化（双击启动时等于 exe 目录）。
- 留空 → 使用该类型的默认目录（见下表）。
- 目录不存在会自动创建。

| 类型 | 留空时的默认目录 |
|------|-----------------|
| 软件 | `X:\TOOL` |
| bat / 驱动 | `X:\TOOL\BAT` |
| cmd | `X:\TOOL\CMD` |
| wcs | `X:\TOOL\WCS` |
| CMD | 不使用（不落文件）|

#### 3.5 占用大小（第 5 字段，可空）

- 只对 `软件` / `驱动` 生效；其它类型填了也按 0 计。
- 单位 `KB` / `MB` / `GB`，不区分大小写，支持小数：`800KB`、`12.5MB`、`1.5GB`。
- **纯数字按 KB**：`500` 等于 500 KB。
- 不填或写错 → 0（只影响「共 X GB」汇总显示，不影响转换）。
- 作用：勾选后状态栏显示「已选 N 项 · 共 X GB」，用来判断 `X:` 内存盘空间是否够。

### 4. 最终落点怎么算

第 4 字段是**父目录**，程序会在它下面再拼一层名称：文件夹 / 压缩包拼「文件夹名 / 包名」，单文件拼「文件名」。

| 类型 | 源 | 第 4 字段 | 最终结果 |
|------|----|----------|---------|
| 软件 | 文件夹 `D:\Apps\Browser` | 空 | `X:\TOOL\Browser\`（整个文件夹拷进去）|
| 软件 | 单文件 `D:\Tools\PECMD.EXE` | `X:\Tools\PECMD` | `X:\Tools\PECMD\PECMD.EXE` |
| 软件 | `D:\Packages\Tools.zip` | 空 | `X:\TOOL\Tools\`（解压到去掉扩展名的子目录）|
| 软件 | `D:\Packages\Tools.7z` | `X:\Apps` | `X:\Apps\Tools\` |
| bat | `D:\Scripts\Clean.bat` | 空 | `X:\TOOL\BAT\Clean.bat`，随后执行 |
| cmd | `D:\Scripts\Info.cmd` | 空 | `X:\TOOL\CMD\Info.cmd`，随后执行 |
| wcs | `D:\Scripts\Net.wcs` | 空 | `X:\TOOL\WCS\Net.wcs`，随后 `PECMD LOAD` |
| 驱动 | `D:\Drv\Net.inf` | — | 不复制，原地安装 |
| 驱动 | `D:\Drv\Pack.7z` | — | 不复制，交给 `DrvIndex.exe` |
| CMD | `notepad.exe` | — | 直接执行，不落文件 |

一句话：**要精确控制落点就写第 4 字段，并记住它是目录、不是文件名。**

### 5. 六种类型详解

#### 软件

- 动作：文件夹递归拷贝、`.zip` 解压、`.7z` 解压、其它单文件直接拷贝。
- 失败自动重试 3 次（间隔 500ms），仍失败则**静默放弃**，界面不会弹错误（去目标目录确认即可）。
- 同名文件直接覆盖；目标里多出来的旧文件不会被删除。

#### 驱动

- `.inf`：调用 Win32 `DiInstallDriverW` **原地安装**，不复制到 `X:\`，**需要管理员权限**。
- `.zip` / `.7z` / 文件夹：调用**同目录** `DrvIndex.exe -b <源> -hide`，由它解包并安装。
- 第 4 字段对驱动没有实际作用（默认目录仍会被创建）。
- 驱动包安装是异步的，界面显示「完成」时驱动可能还在装，稍等再刷新设备管理器。

#### bat / cmd

- 先复制到目标目录，随后自动处理：转 **GBK**、换行统一 **CRLF**、首行插入 `@chcp 936 >nul`（脚本已以 `@chcp` 开头则跳过）。
- 用 `cmd /c <复制后的脚本>` 执行，会弹出独立控制台窗口，能看到输出。
- 脚本里引用同目录资源请用 `%~dp0`，不要依赖当前目录。

#### wcs

- 复制到目标目录后，若文件开头 200 字节内没有 `#code=`，自动补一行：UTF-8 → `#code=65001`，GBK → `#code=936`（不改变原编码）。
- 再用 `PECMD.EXE LOAD <复制后的文件>` 执行。
- PECMD 查找顺序：exe 同目录 → 系统 `PATH`。

#### CMD（大写）

- 第 2 字段整行当命令行：**不检查、不复制、不落文件**，始终显示「可用」。
- 以 `start` 开头：直接启动 `start` 后面的程序；`start /min xxx` 这类带参数的写法不支持（`/min` 会被当成程序名）。
- 其它写法：走 `cmd /c <命令行>`，支持管道、重定向、`&&`。
- 命令行里不能出现英文逗号（会被当字段分隔）。

### 6. 同名合并与执行顺序

```ini
驱动,D:\Drivers\NetCard.inf,网络支持,,100MB
wcs,D:\Scripts\NetSetup.wcs,网络支持,
```

- 界面只出现**一个**「网络支持」勾选项，位置按它**第一次出现**的行。
- 勾选后按**书写顺序**依次执行：先装驱动，再跑脚本。
- 可用性取**与**：任一源缺失 → 整项显示「缺失」。
- 大小累加：`100MB + 0 = 100MB`。
- 该选项全部动作跑完后，才写一次「已内置」标记。

### 7. 常用模板

```ini
; ── 绿色软件（文件夹 / 压缩包 / 单文件混用）──
软件,D:\Apps\Browser,浏览器,,50MB
软件,D:\Packages\DiskGenius.7z,分区工具,,30MB
软件,D:\Tools\PECMD.EXE,PECMD 主程序,X:\Tools\PECMD,2MB

; ── 网卡驱动 + 配置脚本，合并成一项 ──
驱动,D:\Drivers\NetCard.inf,网络支持,,8MB
wcs,D:\Scripts\NetSetup.wcs,网络支持,

; ── 系统清理脚本 ──
bat,D:\Scripts\Clean.bat,系统清理,

; ── 不落文件的即时命令 ──
CMD,cmd /c ipconfig /all > X:\net.txt,导出网络信息,
```

### 8. 排错速查

| 现象 | 原因与处理 |
|------|-----------|
| 界面里根本没有这个选项 | 该行少于 3 个字段；类型或显示选项为空；被当成了注释 |
| 显示「缺失」 | 源路径不存在；相对路径是相对 **exe 目录**，不是 ini 目录 |
| 勾选后什么也没发生 | 类型拼写不对（`软体`、`BAT`）；或把 `cmd` / `CMD` 用混了 |
| 文件没落到预期位置 | 第 4 字段是**父目录**，最终路径还会再拼一层名称 |
| 复制到 `X:\` 失败 | `X:` 不存在或空间不足；本地测试请把第 4 字段改成真实目录 |
| 脚本中文乱码 | 工具已转 GBK 并加 `@chcp 936`；若脚本内部又切换了 `chcp`，请去掉 |
| wcs 中文乱码 | 文件里已有 `#code` 时工具不会改写，请手动改成 65001 / 936 |
| 驱动装不上 | `.inf` 需管理员权限；压缩包 / 目录需同目录有 `DrvIndex.exe` |
| 一直显示「已内置」 | 标记存在 `HKLM\SOFTWARE\WZZNZ\Installed`，删除对应值即可恢复「未内置」|

## 命令行模式

带 `--auto` 参数运行，**不显示界面**，读取配置、全选并转换（适合无人值守 / 自动化）：

```bat
外置转内置.exe --auto
```

输出示例：

```
[auto] 已加载 8 个选项
[auto] 转换完成，共处理 8 项。
```

## 运行时依赖（同目录文件）

工具会把内嵌资源释放到**自身所在目录**，也优先在该目录查找：

| 文件 | 用途 | 何时需要 |
|------|------|---------|
| `dwrite.dll` | 文字渲染 | 内嵌，PE 缺此 DLL 时释放 |
| `PECMD.EXE` | 执行 `wcs` 类型 | 有 wcs 项时 |
| `DrvIndex.exe` | 安装驱动包 | 有驱动压缩包 / 目录项时 |
| `7z/7z.exe`、`7z/7z.dll` | 解压 `.7z` | 有 7z 压缩包时 |

## 从源码构建

环境要求：**Rust 1.75+**（`x86_64-pc-windows-msvc` 工具链）+ Visual Studio Build Tools。

```bash
# 开发构建
cargo build --release
# 产物：target/release/外置转内置.exe

# 一键构建发布包（编译 + 复制 exe / README / 配置到 dist/）
build.bat
```

- 静态链接：`.cargo/config.toml` 中 `+crt-static`
- 图标：`assets/icon.ico`（`build.rs` 用 `winres` 嵌入）
- 内嵌资源：`res/` 目录（`rust-embed`），`build.rs` 生成 CRC32 哈希用于运行时校验
- **修改 `res/` 后需重新构建**，否则哈希校验不通过

### 项目结构

```
wind/
├── .cargo/config.toml      静态链接配置
├── assets/icon.ico         exe 图标
├── res/                    内嵌资源（运行时释放到 exe 同目录）
│   ├── dwrite.dll
│   ├── PECMD.EXE
│   ├── DrvIndex.exe
│   └── 7z/{7z.exe,7z.dll}
├── src/main.rs             全部逻辑
├── build.rs                图标嵌入 + res/ 哈希生成
├── Cargo.toml
├── build.bat               一键构建 → dist/
├── 示例配置.ini            带注释的配置模板
└── README.md
```

## 注意事项

1. `外置转内置.ini` 必须与 `外置转内置.exe` **同目录**。
2. 第 4 字段「目标文件夹」填**绝对路径**；留空才用默认 `X:\TOOL\...`。正常 Windows 下没有 `X:` 盘，本地测试请显式指定目标目录。
3. **驱动安装需管理员权限**；`.inf` 走 Win32 API，压缩包 / 目录走 `DrvIndex.exe`。
4. `bat` / `cmd` 若含中文，工具会自动转 GBK 并注入 `@chcp 936`，一般无需手动处理。
5. 在真实 PE 中运行前，请确认 `X:\`（内存盘）有足够空间。
6. 本工具为**纯 GDI 界面**，可在精简 PE 中运行（无需 OpenGL / DirectX）。
7. 频繁运行 `build.bat` 会用 `示例配置.ini` 覆盖 `dist\外置转内置.ini`，注意备份。
